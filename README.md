## 🎯 Project Overview
This Python automation script processes daily sales data from Excel spreadsheets (`.xlsx`), calculates key business performance metrics, and automatically generates and sends an executive report via email to stakeholders and leadership.

It streamlines operational processes, eliminating manual data aggregation and repetitive reporting tasks.

---

## 🛠️ Tech Stack & Tools
- **Python 3.x**: Core programming language.
- **Pandas**: Data manipulation, cleaning, and aggregation.
- **PyWin32 (`win32com.client`)**: Automated integration with Microsoft Outlook for email delivery.

---

## 📊 Key Automated Metrics
The script aggregates sales data by store/location to compute:
1. **Total Revenue** per store.
2. **Total Units Sold** per store.
3. **Average Ticket** (Average order value) per store.
